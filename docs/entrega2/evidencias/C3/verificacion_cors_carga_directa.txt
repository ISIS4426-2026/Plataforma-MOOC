- maxAgeSeconds: 3600

  - PUT
  - OPTIONS
  origin:
  - '*'
  responseHeader:
  - '*'

  -H "Origin: https://plataforma-mooc-frontend.example.com" \
  -H "Access-Control-Request-Method: PUT" \

CONCLUSION:
1. La peticion preflight OPTIONS desde un origen externo devuelve HTTP 200 con:
   - access-control-allow-origin: * (permite el origen del cliente web)
   - access-control-allow-methods: GET,HEAD,PUT,OPTIONS (autoriza el metodo PUT de carga directa)
   - access-control-allow-headers: Content-Type
   - access-control-max-age: 3600
2. La carga directa (HTTP PUT) con la URL firmada emitida por la API se completa
   exitosamente (HTTP 200 OK) e incluye la cabecera access-control-allow-origin,
   satisfaciendo la verificacion CORS del navegador.
