================================================================================

credencial se escribe en la evidencia.

2) GET condicional: el ETag que coincide ahorra el cuerpo
   If-None-Match con el ETag correcto  -> HTTP 304
   If-None-Match con un ETag distinto  -> HTTP 200
   Sin If-None-Match                   -> HTTP 200

3) La insignia de otro no se distingue de una que no existe
   Sin sesion                          -> HTTP 401
   Con sesion de otro usuario          -> HTTP 404
   Un id inexistente                   -> HTTP 404

4) Verificacion publica: el enlace de la insignia, SIN cabecera Authorization
